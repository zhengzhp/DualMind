正文（中英混排）

浏览器扩展是一种运行在浏览器内部的小型软件。A browser extension is a small program that runs inside the browser and can observe and modify the pages you visit. 它既可以只是只读地整理信息，也可以在**明确授权**后代表你执行若干操作。

语言模型的能力边界取决于它是否支持工具调用。Tool calling lets a model ask the host application to perform an action, such as reading a page element or filling a form field. 没有工具调用的模型只能输出文本，无法与页面交互，因此 在需要操作页面时应明确提示用户更换模型，而不是静默退化成胡乱点击。

安全设计上，最重要的原则是「先展示计划，再执行动作」。Plan first, then act. 对于提交表单、删除数据这类不可逆操作，应在执行前再次确认；而对于支付、 转账一类高风险动作，应当直接拒绝自动执行，而不提供「仍然执行」的旁路。

列表

  • 只读能力：读取正文、抽取文本、总结要点。
  • 写入能力：点击按钮、填写输入框、选择下拉项。
  • 导航能力：滚动、跳转锚点；离开当前页面属于危险动作。
  • 限制：Shadow DOM 与跨域 iframe 内的元素通常无法直接操作。

隐私是本地优先工具的核心理由。Local-first tools process your data on your own machine, which means the content you are reading does not have to leave your computer unless you explicitly send it to a model endpoint you configured. 即便如此，用户仍然需要清楚地知道：哪些数据会被发送、发送到哪里、以及如何删除它们。

可用性方面，错误信息应当是可读的。An error message should tell the user what went wrong and what to do next, without leaking credentials or internal details. 例如「模型不支持工具调用，请更换模型」就比「请求失败」更有帮助。

可靠性方面，任何自动化都应当可以被随时中止。Cancellation must be honored promptly: once the user stops a task, no further page actions should be taken, even if a slow network response arrives later.
