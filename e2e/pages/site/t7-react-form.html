T7 · 受控表单（React value tracker 语义）

对应用例：AG-09。用于验证 fill / type 是否**真的更新了应用状态**， 而不是只改了 DOM 外观被浏览器短暂显示、随后被框架回写覆盖。

⚠️ 读法警告（曾导致误报 DM-V3-001，已撤回）：本页脚本在主世界，扩展内容脚本在 隔离世界。React 的 value tracker 装在主世界的节点包装对象上，隔离世界的 node.value = x 碰不到它，会落到原生 setter，于是 tracker 滞后、框架判定「有变化」并触发 onChange —— 行为等价原生 setter 路径。 所以在本页控制台里手工直写会「失败」，但真实扩展的 fill 会成功。 本页只用于观察机制，不可据本页结论判产品缺陷。

实现说明：本页用原生 JS **精确复现** React 受控输入的关键机制 —— 框架在节点上定义 value 访问器并维护一个「框架认为的值」。直接 node.value = x （内容脚本的做法）会同步该记录，框架随即判定「无变化」，不触发 onChange 并回写受控值。 真实键盘输入与原生 setter 不受此影响。
