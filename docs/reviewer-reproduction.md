# DualMind v1.0.0 审核员复现说明（REL-09）

> 面向 Chrome Web Store 审核。目标：**无需账号、无需付费**即可走完主要功能与安全路径。
> 配套：隐私政策 [PRIVACY.md](../PRIVACY.md) · 权限用途 [store-listing.md](./store-listing.md) · 已知限制 [release-notes-v1.0.0.md](./release-notes-v1.0.0.md)。

## 0. 前置条件

| 项 | 说明 |
|----|------|
| 浏览器 | 桌面版 Chrome（首轮仅 Chrome；Edge 未验证） |
| 模型端点 | **二选一**：① 本机 [Ollama](https://ollama.com/)（推荐，**无需 Key**）；② 任意 OpenAI 兼容服务（需自备 Base URL 与 Key） |
| 账号 | **不需要**注册、登录或付费。扩展没有自有后端，也没有任何开发者账号体系 |

> ⚠️ **审核用凭据**：DualMind 是 BYOK 模式，**不提供**内置 Key。若贵方不便安装 Ollama，可用贵方自己的 OpenAI 兼容端点；**请勿**在公开的复现记录中粘贴真实 Key。

### 0.1 推荐：用本地 Ollama（完全离线、确定性最好）

```bash
ollama pull qwen3:4b     # 该模型支持 tool calling，Agent 路径可用
ollama serve             # 默认 http://127.0.0.1:11434
```

## 1. 安装

1. 解压提交的 zip，得到含 `manifest.json` 的目录。
2. Chrome → `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择该目录。
3. 出现「读取并更改您在所有网站上的数据」警告属**预期行为**（原因见 store-listing 的权限用途）。

## 2. 配置模型

1. 点击扩展图标右侧的「设置」（或 `chrome://extensions` → 扩展详情 → 扩展程序选项），打开 **Options**。
2. **Ollama**：确认 Host 为 `http://127.0.0.1:11434` → 点「刷新列表」→ 选择 `qwen3:4b`。
   **OpenAI 兼容**：填写 Base URL（**需含 `/v1`**）、API Key、模型名。
3. 可点「测试连接」确认成功。

## 3. 验证翻译（核心功能）

1. 打开任意 `http(s)` 网页（如 <https://example.com>）。
2. 选中一段文字 → 按 `Alt+K`（macOS：`Option+K`）。
3. **预期**：出现划词浮层并**流式**输出译文；点浮层上的「侧边栏」可打开**真实 Side Panel** 并承接该选区。

## 4. 验证阅读助手（只读）

1. 把鼠标移到页面右下角的 DualMind 悬浮按钮 → 展开动作 → 点「**总结本页**」。
2. **预期**：Side Panel 内流式输出当前页摘要；可继续追问。该能力**不写页面**。

## 5. 验证本页 Agent（计划批准 → 执行）

为便于复现，仓库内置了一个本地测试页：

```bash
node e2e/pages/serve.mjs      # 起静态服务器
```

然后打开 <http://127.0.0.1:4173/t1-static-form>（一个带「姓名 / 备注」等字段的表单页）。

1. 打开 Side Panel → 切到 **Agent** Tab。
2. 输入目标，例如 `把姓名填成张三，不要提交` → 点「开始」。
3. **预期（闸门）**：先展示**步骤计划**，此时页面**不应发生任何写入**；点「**批准并执行**」后才执行。
4. **预期（执行）**：Agent 通过工具观察并填写「姓名」；完成后显示「任务成功完成」，页面上「姓名」变为 `张三`，且**没有**触发提交。
5. 随时可点「**停止**」中断。

### 5.1 危险动作二次确认

1. 目标改为 `把草稿删掉` → 开始 → 批准。
2. **预期**：出现「**危险动作待确认**」，需点「仍要执行」才会执行；点「跳过」则不执行。

### 5.2 资金类动作被拒绝（关键安全行为）

1. 打开 <http://127.0.0.1:4173/checkout>（模拟支付页）。
2. 目标：`立即完成支付` → 开始。
3. **预期**：扩展**直接拒绝**（不会执行支付、界面上**没有**可绕过的「仍要执行」按钮）。

## 6. 无需模型也能验证的部分

即使未配置任何模型，也可确认：

- 三个权限请求的提示与理由一致；
- 未配置模型时，各功能给出**可读错误文案**（不会静默失败或无限 loading）；
- Options 页可保存 / 回读设置；
- 「禁用站点」列表生效（列入的站点不注入划词工具栏与悬浮入口）。

## 7. 声明

- **单一用途**：在网页中提供基于用户自带模型的翻译、只读阅读助手与可选本页 Agent（详见 store-listing）。
- **远程代码**：否。所有逻辑随包发布，运行时仅从**用户配置的**端点获取文本结果。
- **数据收集**：否。无遥测；数据仅在用户本机与用户配置的端点之间传输（详见 PRIVACY.md）。
- **Agent 边界**：仅当前页、不跨 Tab、不使用 `debugger`/CDP、资金类动作直接拒绝。
