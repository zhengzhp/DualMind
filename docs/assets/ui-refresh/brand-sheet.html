安全边距与最小尺寸

x = 折缝宽度
  • 四周留白 ≥ 1x（x = 折缝宽度）
  • 标记最小 16px；组合标最小宽度 120px
  • 16/32px 用实心简化标；48px 以上用带折缝主标

不要这样做

  • 不要拉伸/压扁：标记宽高比固定 240:280。
  • 不要加描边、投影或渐变：折缝必须保持透明/底板色，不另加第三种颜色。
  • 不要把折缝宽度改回 3.5%：16px 会消失；也不要在 16px 强行保留折缝。
