04 · 诊断

  • 小尺寸16px 下，深蓝/浅蓝的分割退化成一块灰角，"双 D"读不出来，只剩一个模糊的 D。
  • 底色标记依赖渐变底板；深底上蓝色底板与页面接近，边缘要靠白环撑住。
  • 单色没有单色 / 反白版本，图标一旦要去掉渐变就失去识别点。
  • 一致性图标是硬边几何，字标是自绘轮廓，两者没有共同网格。
  • 保留蓝色的气质与"双"的概念是对的；问题在造型，不在配色。

05 · 新标必须通过

  • 16px 剪影可辨（不靠颜色）
  • 纯黑 / 纯白 / 单蓝三态成立
  • 与字标共用一套几何比例
  • 深浅底都不加描边
  • 提供 16 / 24 / 32 简化标
